# V2 Frontend Foundation

This Next.js/TypeScript shell is non-authoritative in Phase 1. It does not replace or control the Streamlit application.

```powershell
cd v2\frontend
npm.cmd install
npm.cmd run dev
```

- Next.js development: `http://localhost:3000`
- V2 FastAPI: `http://localhost:8000`
- Legacy Streamlit: `http://localhost:8501`

Template Studio and workflow links are navigation placeholders only. The shell contains no AI integration or production-data connection.
