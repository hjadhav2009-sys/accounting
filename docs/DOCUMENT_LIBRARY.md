# Document library

Tenant-scoped APIs provide upload, background batch, list/search/filter, detail, protected content/page image, extraction and validation. Filters cover selected company context, dates, type, supplier, document/validation/review/duplicate state, format family and uploader. Search covers filename, invoice/reference and supplier. Clear-all and URL query state support local revisits.

The detail viewer uses protected page renderings and a reusable overlay layer. Clicking a field, OCR token or table navigates to its page and draws the real normalized box. Controls provide previous/next page, scroll-pan, zoom, fit-width and fit-page. Evidence without coordinates states “Source location unavailable.” Unknown documents display “NEW FORMAT DETECTED,” quality, OCR use, routing explanation and read-only review action.
