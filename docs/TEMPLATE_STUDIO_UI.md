# Template Studio UI

Routes are `/templates`, `/templates/{familyId}`, `/templates/routing`, `/template-studio` and `/template-studio/{versionId}`. Unknown documents open automatic deterministic drafts. The editor offers high-quality protected page images, thumbnails, zoom, page navigation, field/table/ignore drawing, pointer drag/resize, table columns and row classifiers, anchor editing, safe derived rules, source-linked preview, validation, sample tests and version diff.

Side panels use viewport space and CSS resizing; the bottom dock separates extraction, tests, diff, “why”, activity and the explicitly disabled Phase 5 assistant. Desktop is primary. Only active pages render at full canvas size.
