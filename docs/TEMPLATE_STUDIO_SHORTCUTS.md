# Template Studio shortcuts

- `V` pointer; `H` hand/pan; `R` region; `T` table.
- `Ctrl+Z` undo; `Ctrl+Shift+Z` redo; `Delete` selected draft mapping; `Esc` clear selection.
- `+`/`-` zoom; `Ctrl+S` save; `Ctrl+K` deterministic command palette.

Shortcuts do not fire while typing in an input/select/textarea, except deliberate browser-standard save/undo and the palette command.
